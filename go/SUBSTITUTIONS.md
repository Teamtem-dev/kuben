# Substitution ledger

Every place where the Go code replaces Rust code or a Rust crate with a
different library, or with a port whose semantics could drift, has a row
here. A pull request that adds a dependency or swaps an implementation
without a row is not merged (plan §3, principle 3: a substitution is a
behaviour change until proven otherwise).

| Area | Rust | Go | Known differences and how they are closed | Pinned by |
|---|---|---|---|---|
| Semver ranges (image policies) | `semver` crate `VersionReq` | Port of the crate's range grammar, `Display` and matching (`core/imagepolicy/req.go`); `Masterminds/semver/v3` only parses tag versions (`StrictNewVersion`) | Masterminds reads bare `1.2.3` as exact (Rust: caret), treats spaces as AND, has `\|\|`, matches pre-releases more widely → not used for ranges. Masterminds rejects versions over 256 bytes; OCI tags are at most 128. | `imagepolicy_test.go`, 2 fuzz targets |
| Tag globs | hand-written matcher | byte-for-byte port | `path.Match` not used (it treats `/`, `?` and classes specially) | `imagepolicy_test.go` |
| Domain names (IDNA) | `idna::domain_to_ascii` | `golang.org/x/net/idna` custom profile: MapForLookup, BidiRule, CheckJoiners, no hyphen/STD3/DNS-length checks, then the Rust LDH and length checks | `idna.Lookup` rejects `ab--cd.com` and applies STD3 → not used. Unicode table versions differ (x/net: Unicode 17): a newly assigned code point could map differently; x/net is pinned and existing domains are checked before cutover C1. | `domain_test.go` (+ quick property) |
| Advisory lock keys | `domain::lock_key` | same bytes | none | `domain_test.go` |
| Timestamps from GitHub | `jiff::Timestamp::from_str` | `time.Parse(time.RFC3339Nano)` | Go rejects lowercase `t`/`z`, space separator, `:60`, RFC 9557 suffixes; GitHub sends none. Pre-1970 fractions floor instead of truncate. | `source_test.go` |
| Configuration | `figment` (defaults → /etc/kuben/config.toml → ./kuben.toml searched upward → `KUBEN_*` with `__`) | `koanf/v2` + a port of figment's env-value grammar + own nesting (koanf's `maps.Unflatten` clobbers tables) + strict mapstructure decoding | Decode error texts differ. A bare number/boolean for a text setting from env is accepted as text (figment refused it unquoted) — accepted by the owner 2026-09-21. | `config` tests, `FuzzEnvValue` |
| Secrets in configuration | plain `String` | `config.Secret` (redacted in fmt/%v/%+v/%#v/%d/JSON) | `sso.client_secret = ""` means unset — accepted 2026-09-21. | `config` tests |
| Canonical JSON and content hashes | `render::canonical` over `serde_json::Value` | `wire.Canonical`: byte-sorted keys; serde's string escaping (not DEL, U+2028/2029, `<>&`); serde's float printing (plain for exponents −5…15, else `1e+21`/`1e-6`); a port of serde_json's number *parser*, which is not correctly rounded (`strconv.ParseFloat` differs on 3 of 18 pinned texts), with the literal 1e0…1e308 table (`math.Pow10` differs at 78 exponents) | none known; canonical text with floats is not a fixed point, in Rust either | `testdata/compat/{canonical,floats}.json` from Rust (6 documents, 4000 floats, 18 number texts); fuzz |
| Other JSON output | `serde_json` | `encoding/json` with `SetEscapeHTML(false)` where bytes are a contract (webhook bodies, stored JSON) | `encoding/json` escapes `<`, `>`, `&` and U+2028/2029 by default | per package |
| Rust `{:?}` in messages | Debug formatting | `%q` / local `rustQuote` | differs only for control and grapheme-extend characters | package tests |
| HTTP API server | axum + utoipa (code first) | ogen v1.24 (spec first, server only) from the unchanged `openapi.json` | Generated `Opt*`/`OptNil*` DTOs instead of domain types: converted at the route layer. The two SSE endpoints are hand-written handlers. ogen validates requests from the spec (enums, formats, required members). A gate checks the principal before decoding, as axum's extractor order did; a malformed request from a signed-in caller answers 422 validation_failed (axum: plain-text 400 for query rejections). | `go/SPIKES.md`; route tests (S1+) |
| Agent kind→resource mapping | kube-rs discovery | client-go discovery + `restmapper.NewDeferredDiscoveryRESTMapper` over a memory cache | Same answers for served resources; the mapper is reset when a kind is not found (CRDs installed later). | agent tests (S2) |
| Schema migrations and their ledger | `sqlx::migrate!` (sqlx-core/sqlx-postgres 0.9) on `_sqlx_migrations` | `store/migrate`: a port of sqlx's resolver and Postgres migrator on the same table, rows and advisory lock; `store/migrations` embeds byte-identical copies of the 33 files | Same: checksum = SHA-384 of the file bytes (sqlx strips nothing without a sqlx.toml, and Kuben has none); name split at the first `_`, i64 version, description = rest minus the `.sql`/`.up.sql`/`.down.sql` suffix (repeatedly, `trim_end_matches`) with `_` → space; `-- no-transaction` prefix; lock id `0x3d32ad9e × crc32_ieee(current_database())`; lock → ensure table → dirty check → missing check → per migration: checksum compare or apply (SQL by simple protocol + ledger row with `execution_time = -1` in one transaction, then `UPDATE … execution_time = ns`) → unlock. Differences: after a failed run sqlx leaves the session lock on a pooled connection; the Go store closes that connection. `undo`, `skip`, `run_to`, `ignore_missing` and schema creation are not ported (Kuben never used them). Database error texts inside `while executing migration N: …` are pgx's, not sqlx's. | `migrate_test.go` (pinned checksums from `shasum -a 384`, lock ids from zlib.crc32, name rules, ledger rows and refusals against PostgreSQL), `migrations/embed_test.go` (byte-identical to the Rust files while they exist) |
| PostgreSQL driver and pool | sqlx `PgPool` (typed binds, prepared-statement cache, `acquire_timeout(10 s)`, `max_connections(max(n, 2))`, idle 10 min, lifetime 30 min) | pgx v5 `pgxpool` behind `store.pool`, which bounds every acquisition by 10 s (pgxpool has no acquire timeout) | sqlx sent a type with every bind; pgx lets the server infer parameter types, so `INSERT … SELECT $n` relies on PostgreSQL coercing the unknown parameter to the column type (true since PG 10, not exercised in the sandbox; CI runs every statement). URL parsing is pgx's `ParseConfig` (libpq rules; sqlx's own parser accepted the same URLs Kuben documents). Database error texts differ (`database error: <op>: ERROR: … (SQLSTATE …)`). JSON written to text/jsonb columns goes through `wire.CanonicalValue`, serde_json's `Value::to_string`; content hashes (`releases.content_hash`, `render_plans.content_digest`, `target_config_revisions.config_hash`) are taken over that text, so a JSON float must reach the store as `json.Number` to keep serde's `1.0` (a `float64` prints `1`). Where the server would infer another type than sqlx bound, because a parameter's first use is a cast or a comparison, the Go SQL casts it where it is stored, to the type Rust bound: `deployments.go` INSERT_RUN `$1::uuid, $5::uuid, $6::uuid, $7::uuid, $9::bigint, $10::uuid` (first used in `::text` for the approval plan hash) and `$15::smallint` (first used in `$15 > 0`, an integer). Rust tuples in JSON output (`SupportSummary`) are arrays through `MarshalJSON`. | store tests against PostgreSQL 17 in CI; `TestIDsEncodeAndScanForBothColumnTypes` (ids through pgx in text and uuid columns, no database) |
| CRD types (kuben.dev/v1alpha1) | `serde` derives + kube-rs `CustomResource`/`KubeSchema` (`validate_cel` in tests) | `kubenapi/v1alpha1`: Kubernetes-style types, serde defaults and skip rules reproduced by `UnmarshalJSON`/`MarshalJSON`, enums refuse unknown strings; DeepCopy by controller-gen; the tests validate with the apiextensions-apiserver OpenAPI and CEL validators over the frozen manifest | Go is more lenient on decode: a missing required member, `null` for a non-nullable one and duplicate keys are accepted (serde refused them; the apiserver's schema refuses the first two). Types with a custom decoder match member names case-insensitively (`encoding/json`), serde and `sigs.k8s.io/json` case-sensitively. Unsigned widths kept (`uint16` ports, `uint32` counts) to match the manifest's formats. Zero enums encode as the Rust `#[default]` variant. | `objects_test.go` (34 fixtures against the Rust oracle `testdata/rust-oracle.rs.txt`), `schema_test.go` |
| Kubernetes watches for the projections | kube-rs `runtime::watcher` (+ `default_backoff`, `.modify` clearing managedFields), `Init/InitApply/InitDone` staging, `tokio::sync::broadcast(1024)` fan-out | client-go `SharedInformerFactory` (Pods, label `app.kubernetes.io/managed-by=kuben`) and dynamic informers (Projects, Environments, Apps; HTTPRoutes with the same selector; cert-manager Certificates filtered to `kuben-tls-*`) with a transform that drops managedFields; `platform/projection` | The first LIST is swapped in once the informer reports synced (adds of the initial list are ignored, so readers never see a half set). A later re-list arrives as individual upserts and deletes (client-go's Replace), not as a `resync` delta; the Rust watcher emitted `resync` on every re-list. kuben.dev objects are decoded through their `UnmarshalJSON` (serde defaults); an undecodable one is skipped with a warning. Fan-out: one bounded queue (1024) per subscriber; on overflow the backlog is dropped and the next receive is a lag notice with the missed count (Rust: `Lagged(n)` then the oldest retained deltas). Views and deltas are encoded by `encoding/json` without HTML escaping at the top level, but `opt.Val` members still escape `<`, `>`, `&` (`\u003c`) and U+2028/2029, and `stream.Serve` HTML-escapes the snapshot: the same JSON values, not always the same bytes. | `projection` tests (fake clientset, fake dynamic client), `TestDeltasSerializeAsTheRustEnum`, `TestViewsSerializeAsTheRustStructs` |
| Render plan objects | k8s-openapi typed objects serialized by serde (unset `Option`s absent) | JSON maps built field by field in `platform/render` (typed client-go objects would add `creationTimestamp: null`, `status: {}`, `strategy: {}` …) | none known: the three Rust golden snapshots are compared byte for byte, and the canonical text goes through `wire.CanonicalValue` | `render` golden tests (`testdata/*.snap`) |
