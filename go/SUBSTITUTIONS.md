# Substitution ledger

Every place where the Go code replaces Rust code or a Rust crate with a
different library, or with a port whose semantics could drift, has a row
here. A pull request that adds a dependency or swaps an implementation
without a row is not merged (plan §3, principle 3: a substitution is a
behaviour change until proven otherwise).

| Area | Rust | Go | Known differences and how they are closed | Pinned by |

| PostgreSQL driver and pool | sqlx `PgPool` (typed binds, prepared-statement cache, `acquire_timeout(10 s)`, `max_connections(max(n, 2))`, idle 10 min, lifetime 30 min) | pgx v5 `pgxpool` behind `store.pool`, which bounds every acquisition by 10 s (pgxpool has no acquire timeout) | sqlx sent a type with every bind; pgx lets the server infer parameter types, so `INSERT … SELECT $n` relies on PostgreSQL coercing the unknown parameter to the column type (true since PG 10, not exercised in the sandbox; CI runs every statement). JSON written to text/jsonb columns goes through `wire.CanonicalValue`, serde_json's `Value::to_string`; content hashes (`releases.content_hash`, `render_plans.content_digest`, `target_config_revisions.config_hash`) are taken over that text, so a JSON float must reach the store as `json.Number` to keep serde's `1.0` (a `float64` prints `1`). | Kubernetes watches for the projections | kube-rs `runtime::watcher` (+ `default_backoff`, `.modify` clearing managedFields), `Init/InitApply/InitDone` staging, `tokio::sync::broadcast(1024)` fan-out | client-go `SharedInformerFactory` (Pods, label `app.kubernetes.io/managed-by=kuben`) and dynamic informers (Projects, Environments, Apps; HTTPRoutes with the same selector; cert-manager Certificates filtered to `kuben-tls-*`) with a transform that drops managedFields; `platform/projection` | The first LIST is swapped in once the informer reports synced (adds of the initial list are ignored, so readers never see a half set).
